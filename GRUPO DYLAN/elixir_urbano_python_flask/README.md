# Elixir Urbano en Python + Base de Datos + CRUD

Este proyecto fue transformado a Python con Flask y quedó listo para:
- crear base de datos
- registrar usuarios
- iniciar sesión
- hacer CRUD de productos
- mantener los nombres de tus archivos HTML y CSS

## Archivos HTML conservados
- index.html
- login.html
- productos.html
- proyectoelixirurbano.html
- proyectofinal.html
- registro.html

## Archivos CSS conservados
- style.css
- styleregistrer.css

## Cómo ejecutar
1. Instala dependencias:
   pip install -r requirements.txt

2. Ejecuta:
   python app.py

3. Abre:
   http://127.0.0.1:5000/

## Base de datos
Por facilidad el proyecto corre con SQLite automáticamente.
Se crea el archivo:
- elixir_urbano.db

## MySQL
Dentro de app.py ya te dejé comentado el bloque para pasar a MySQL cuando quieras.
